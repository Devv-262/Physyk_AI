PPT SLIDE TEXT — Pick-and-Place (6-7 technical, defined lines)

- Instruction Parsing: extracts the source object and destination target from natural-language commands.
- Physics Simulation: executes robot motion using a Franka Panda arm in NVIDIA Isaac Sim, with real gravity, contact, and friction.
- Deterministic Control: a validated 10-phase grasp-and-place state machine is the default execution path.
- Motion Planning: RMPFlow generates collision-aware joint targets, routing the arm around registered obstacles.
- Grasp Confirmation: gripper opening width is checked against a minimum threshold after closing, distinguishing a real grasp from closing on empty air.
- Obstacle Handling: the target object (and, for stacking, the reference object) is temporarily disabled as an obstacle for the duration of its own task, then re-enabled on completion.
- Outcome Verification: live simulator telemetry — object position and displacement — is compared against the resolved target to determine actual task success, not assumed success.
